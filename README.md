# statistical-analysis

Descripción del proyecto
Se debe realizar un análisis preliminar de las tarifas de telefonía para identificar cuál genera mayores ingresos. Para ello, se trabaja con datos de 500 clientes durante 2018, incluyendo información sobre su ubicación, plan contratado, llamadas realizadas y mensajes enviados.

 El objetivo es analizar el comportamiento de los usuarios y, mediante pruebas estadísticas, determinar qué tarifa aporta más ingresos en promedio para apoyar decisiones del presupuesto publicitario.

Paso 1. Preparación de datos

Se deben limpiar y transformar los datos al formato adecuado, identificando y corrigiendo errores. Luego, calcular por usuario y por mes:
-Número de llamadas y minutos consumidos.
-Cantidad de SMS enviados.
-Volumen de datos utilizados.
-Ingresos mensuales, considerando excedentes sobre el -plan y la cuota mensual correspondiente.

Paso 2. Análisis de datos

Analizar el comportamiento de los usuarios de cada tarifa:
-Consumo mensual de minutos, SMS y datos.
-Cálculo de media, varianza y desviación estándar.
-Creación de histogramas y análisis de las distribuciones.

Paso 3. Prueba de hipótesis

Evaluar estadísticamente si:
-Los ingresos promedio entre las tarifas Surf y Ultimate son diferentes.
-Los ingresos promedio de usuarios de Nueva York–Nueva Jersey difieren de otras regiones.

Además, definir:

Hipótesis nula y alternativa.
Nivel de significancia (alfa).
Criterio estadístico utilizado.
Paso 4. Conclusión general
